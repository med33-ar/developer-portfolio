# Developer Portfolio

Portafolio personal para presentar información sobre mí, mis habilidades y mis proyectos de desarrollo web.

## Contenido

- Presentación personal
- Sección «Sobre mí»
- Lista de habilidades
- Tarjetas de proyectos
- Información de contacto
- Diseño adaptable a móviles y escritorio
- Menú móvil interactivo

## Tecnologías

- HTML
- CSS
- JavaScript

## Cómo usarlo

1. Clona o descarga este repositorio.
2. Abre `index.html` en tu navegador.
3. Personaliza el contenido con tu nombre, correo, habilidades y proyectos.

No requiere instalación de dependencias ni un proceso de compilación.
